REGRAS DO FIRESTORE — ÁREA DO ALUNO E ÁREA DO PROFESSOR

ANTES DE COLAR
1. Firebase Console > Build > Firestore Database > Rules.
2. Apague as regras atuais.
3. Cole todo o conteúdo abaixo.
4. Clique em Publish / Publicar.

IMPORTANTE: antes de acessar a Área do Professor, crie manualmente no console
uma coleção chamada staff. O ID do documento deve ser o UID do professor
obtido em Authentication > Users. Campos do documento:

active: true
role: "teacher"
name: "Jonatan Vale"

Para o segundo professor, repita com o UID dele e role: "teacher".

REGRAS PARA COLAR

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    function signedIn() {
      return request.auth != null;
    }
    function isStaff() {
      return signedIn()
        && exists(/databases/$(database)/documents/staff/$(request.auth.uid))
        && get(/databases/$(database)/documents/staff/$(request.auth.uid)).data.active == true;
    }
    function owns(studentId) {
      return signedIn() && request.auth.uid == studentId;
    }
    function isPaidStudent() {
      return signedIn()
        && exists(/databases/$(database)/documents/students/$(request.auth.uid))
        && get(/databases/$(database)/documents/students/$(request.auth.uid)).data.enrollmentStatus == 'paid';
    }

    match /staff/{staffId} {
      allow read: if owns(staffId) || isStaff();
      allow write: if false;
    }

    match /students/{studentId} {
      allow read: if owns(studentId) || isStaff();
      allow create, update, delete: if isStaff();
    }

    match /students/{studentId}/progress/{moduleId} {
      allow read: if owns(studentId) || isStaff();
      allow create, update: if owns(studentId) || isStaff();
      allow delete: if isStaff();
    }

    // Vídeos publicados pela equipe acadêmica. O aluno pago só pode ler;
    // professores ativos podem publicar, editar e despublicar gravações.
    match /courseLessons/{lessonId} {
      allow read: if isStaff() || isPaidStudent();
      allow create, update, delete: if isStaff();
    }

    match /assessments/{assessmentId} {
      allow read: if signedIn();
      allow create, update, delete: if isStaff();

      match /submissions/{studentId} {
        allow read: if owns(studentId) || isStaff();
        allow create, update: if owns(studentId) || isStaff();
        allow delete: if isStaff();
      }
    }

    // O gabarito é visível somente a professores.
    match /assessmentKeys/{assessmentId} {
      allow read, write: if isStaff();
    }

    match /liveSessions/{sessionId} {
      allow read: if signedIn();
      allow create, update, delete: if isStaff();

      match /attendance/{studentId} {
        allow read: if owns(studentId) || isStaff();
        allow create, update, delete: if isStaff();
      }
    }

    match /mentorshipRequests/{requestId} {
      allow read: if isStaff() || (signedIn() && resource.data.studentId == request.auth.uid);
      allow create: if signedIn() && request.resource.data.studentId == request.auth.uid;
      allow update, delete: if isStaff();
    }

    // Criadas somente pela rota segura da Hotmart. O aluno não lê vendas nem matrículas por e-mail.
    match /sales/{saleId} {
      allow read: if isStaff();
      allow write: if false;
    }

    match /enrollments/{enrollmentId} {
      allow read, write: if false;
    }
  }
}

COMO CADASTRAR UM ALUNO MANUALMENTE

Coleção: students
ID do documento: UID do aluno visto em Authentication > Users

Campos recomendados:
name: "Nome do aluno"
email: "email@aluno.com"
plan: "profissional"
enrollmentStatus: "paid"
courseStart: "2026-08-10"
driveFolderUrl: "https://drive.google.com/..."

Não cadastre alunos como paid antes da confirmação da compra na Hotmart.

VENDAS E MATRÍCULAS AUTOMÁTICAS

As coleções sales e enrollments são abastecidas exclusivamente pela rota segura
da Hotmart na Vercel. Não as edite pelo navegador do aluno. Professores ativos
podem consultar sales pelo painel financeiro; alunos não têm acesso a esses dados.

OBSERVAÇÃO SOBRE PROVAS

O aluno vê a pergunta e envia a resposta no próprio site. O gabarito fica em
assessmentKeys, que as regras acima permitem somente ao professor. A correção
é feita na Área do Professor; assim, o aluno não consegue ver a resposta certa
no código do navegador.
